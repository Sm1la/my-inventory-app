# Sticky Notes (Post-it Notes)

The inventory and reorder lists group the existing 3M size variants under one expandable heading, with short size labels, their own photos and stock balances. Size order is 2″ × 2″, 2″ × 3″, then 3″ × 3″.

Each size has a Tick box and quantity field. Request selected sizes opens the existing request form with those quantities already selected; requester, department and approver are entered once. Managers also have Receive selected sizes, which opens Add stock with the same selections and quantities and one receipt date. Receipt and request pickers both group the sizes.

Selections are temporary until the existing request or receipt form is submitted. Inventory records, stock balances, approval permissions and transaction validation remain separate for each size. Grouping never merges item IDs or balances. No database changes are required.
